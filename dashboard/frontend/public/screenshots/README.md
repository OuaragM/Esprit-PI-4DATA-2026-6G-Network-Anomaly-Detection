# Dashboard Screenshots

Drop PNG (or JPG) captures of each dashboard page in this folder, named exactly as below.
The landing page **Visite guidée** section will automatically pick them up.

If a file is missing, a stylized placeholder is rendered instead — no broken images.

| File | Page to capture |
|------|-----------------|
| `login.png` | `/login` — sign-in form |
| `dashboard.png` | `/dashboard` — overview / KPIs |
| `upload.png` | `/upload` — CSV upload screen |
| `realtime.png` | `/realtime` — live prediction feed |
| `history.png` | `/history` — past predictions table |
| `drift.png` | `/drift` — drift detection alerts |
| `model.png` | `/model` — MLflow model registry |
| `admin.png` | `/users` or `/settings` — admin view |

## Recommendations

- **Resolution:** 1600 × 1000 px (16:10) — matches the preview frame
- **Format:** PNG with light or dark theme (whichever looks best)
- **Crop:** include the topbar but trim browser chrome
- **File size:** keep under 400 KB each (run through an optimizer like `squoosh` or `tinypng`)
